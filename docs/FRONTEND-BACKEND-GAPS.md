# Frontend ↔ backend gaps

This document lists **missing or incomplete backend connections** and **UI features that are not wired to real APIs** in the ClickUp Sync dashboard (`apps/web`) versus the NestJS API (`src/`). It was generated by reviewing controllers, DTOs, API clients, and pages (May 2026).

---

## Broken or missing API endpoints (frontend calls; backend absent)

| Frontend | Backend | Notes |
|----------|---------|--------|
| `POST /admin/rates/sync` (`adminApi.syncRates`, **Time Entries** “Recalculate” / sync rates) | **No route** in `AdminController` | Mutation always fails until an admin route and worker exist (e.g. enqueue cost recomputation). |

---

## Backend exists; frontend not integrated

| Backend capability | Location | Gap |
|--------------------|----------|-----|
| Dead-letter list | `GET /reports/ops/dead-letters` | `useDeadLetters` exists in `useReports.ts` but **no page imports it**. Sync Logs shows job logs and webhooks only. |
| Dead-letter retry | `POST /admin/dead-letters/:id/retry` | `useRetryDeadLetter` exists in `useAdmin.ts` but **no UI** triggers it. |
| Agency time-entry replacement backfill | `POST /admin/time-entries/backfill-replacement` | Requires `CLICKUP_AGENCY_USER_ID`. **No dashboard action** exposes this. |
| Admin dead-letter list (alternate) | `GET /admin/dead-letters` | Duplicates reporting surface; frontend uses reports path only (and unused). |

---

## Partial / mismatched contracts (works but incomplete or misleading)

| Area | Issue |
|------|--------|
| **PATCH `/admin/rates/:id`** | `UpdateRateDto` only allows `currency`, `hourlyRateCents`, `validFrom`, `validTo`. The app sends `assigneeId`, `assigneeName`, `assigneeEmail` on save; with `ValidationPipe({ whitelist: true })` those fields are **stripped**. You cannot change assignee metadata or re-point a rate via the API as the UI suggests. Extend DTO + `RatesRepository.update` if needed. |
| **POST `/admin/tag-assignee-map`** | `CreateTagAssigneeDto` has no `active` field. UI sends `active` on create; it is **stripped**. New rows always get Prisma default `active: true` (`schema.prisma`). To create an **inactive** mapping, backend must accept `active` on create or use a two-step flow. |
| **PATCH tag mapping** | `UpdateTagAssigneeDto` has no `tagName`. UI includes `tagName` in update payload; it is **stripped**. **Renaming a tag** from Settings does not persist. |
| **Rates list pagination** | `GET /admin/rates` supports `page` / `limit`. Frontend hard-codes `page: 1, limit: 200` in `ratesApi.list` and `reportsApi.assigneeRates`. Large datasets need paging UI or virtual scroll + API params. |
| **Duplicate rates client** | `reportsApi.assigneeRates` and `ratesApi.list` both hit `/admin/rates`. `useAssigneeRates()` is defined but **unused**; `AssigneeRatesPage` uses `useRates()` only. |

## UI-only / placeholder (no backend connection)

### Overview (`OverviewPage.tsx`)

- **Export** button: no `onClick`, no download API.
- **Total tasks** card: `trend={SPARK}` uses a **hard-coded sparkline**, not time-series from the server.
- **“+8.2% vs last 30d”** (and similar deltas where present): **not computed** from backend metrics.
- **Missing rates trend** `LineChart`: **synthetic series** derived from current `missingRateEntries` with `Math.sin`, not real daily history (`GET` for trend does not exist).

### Tasks (`TasksPage.tsx`)

- **Export CSV**: no handler.
- **Backfill** when `space === 'all'': mutation resolves `null` (no-op); only a specific space queues work.

### Time entries (`TimeEntriesPage.tsx`)

- **Export CSV**: no handler.
- **Recalculate** depends on missing `POST /admin/rates/sync` (see above).

### Missing rates (`MissingRatesPage.tsx`)

- **Est. uncosted spend** uses a **fixed placeholder** rate (`PLACEHOLDER_RATE_CENTS_PER_H` = $42/h), not server-provided average or policy default.
- **Export issues**: button has **no `onClick`**.

### Assignee rates (`AssigneeRatesPage.tsx`)

- **Export**: button has **no `onClick`**.

### Settings (`SettingsPage.tsx`)

Large sections are **local React state** or static copy; nothing persists except where noted below.

| Section | Behavior |
|---------|----------|
| Workspace card (“Nifty IT”, workspace id, “Connected”) | **Hard-coded** display, not from ClickUp or env (except webhook URL env). |
| **Test connection**, **Rotate token**, **Disconnect** | `disabled` — **no API**. |
| Webhook **signing secret** field | Masked placeholder string — **not loaded** from `registerWebhook` response or secure store (partially shows `webhookId` after register only). |
| **Sync rules** (reconciliation cadence, rate matching, default currency, webhook retries, failure toggles) | `useState` only — **no GET/POST** settings API. |
| **Scope filters** (“Synced spaces”) | Switches **`checked` + `disabled`** — **no persistence**; space list comes from `GET /reports/spaces` but inclusion toggles do nothing. |
| **Members & access** | Mock members — **no members API**. |
| **Notifications** (channels, alert toggles) | Local state — **no alerting backend**. |

**Wired in Settings**

- `GET /reports/ops/sync-health`, `GET /reports/spaces` (read-only stats).
- Tag–assignee map: `GET/POST/PATCH/DELETE /admin/tag-assignee-map`.
- Register webhook: `POST /admin/webhooks/register`.

### Command palette (`CommandPalette.tsx`)

- Placeholder says “Search tasks, assignees…” but implementation is **navigation shortcuts only** (filters static routes). No task/assignee search API.

### Task detail drawer (`TaskDetailDrawer.tsx`)

- **Sync History** tab shows only `task.syncedAt` from the list row — it does **not** query `GET /reports/ops/job-logs` (or similar) for a full audit trail per task.

### Routing / deep links

- `MissingRatesPage` links to `/assignee-rates?userId=...`.
- **`AssigneeRatesPage` does not read `userId` from the query string** — no auto-filter or modal open for that assignee.

## Auth and ops (intentionally minimal)

- “Login” stores **`adminApiKey` in `localStorage`** and sends **`x-admin-key`** on `/api/*` via Axios (`apps/web/src/api/client.ts`).
- There is **no user session**, OAuth, or role model in the web app.
- **`validateAdminKey`** uses raw `axios.get('/api/admin/ping')` (bypasses `apiClient`); still proxied by Vite to Nest.

## Summary checklist for product/engineering

1. **Implement or remove** `POST /admin/rates/sync` and wire **Recalculate** + any copy that references it.
2. **Dead letters**: add a Sync Logs tab or section using `useDeadLetters` + `useRetryDeadLetter`.
3. **Exports** (Overview, Tasks, Time entries, Missing rates, Assignee rates): implement CSV/JSON endpoints or client-side export from loaded data.
4. **Overview analytics**: replace mock sparkline / trend / delta with real endpoints or remove claims.
5. **Settings**: either persist toggles (new settings table + CRUD API) or label them clearly as “preview / coming soon”.
6. **Space include/exclude**: needs backend model + sync behavior + API; then enable switches.
7. **Rates PATCH**: extend backend if assignee fields should be editable; align payload with DTO.
8. **Tag mapping**: add `tagName` (and optional `active`) to create/update DTOs if the UI should support those operations fully.
9. **Deep link** `?userId=` on Assignee Rates (search highlight or open **New rate** with preset).
10. **Optional**: expose **backfill replacement** admin action with safeguards and env checks.

## Reference: main wired surfaces

These areas generally call Nest with `x-admin-key` as expected:

- Reports: tasks, time entries, sprint points, spaces, sync health, webhook events, job logs, stats, missing rates.
- Admin: task sync, space backfill, webhook register, rates CRUD, tag-assignee CRUD, dead-letter retry (API only).
- Task drawer: single-task sync, time entries list for task.
